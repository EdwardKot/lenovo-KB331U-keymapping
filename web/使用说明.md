# Lenovo KB331U（小新无线键盘 Air）WebHID 离线改键工具使用说明

本工具用于免拆机通过 USB-C 修改联想小新无线键盘 Air（KB331U，`17EF:619E`）顶部 7 个多媒体/快捷功能键的固件映射（修改后**蓝牙与有线双模永久生效**，断电、重新配对不丢失）。

---

## 一、环境要求

- **浏览器**：桌面版 **Google Chrome** 或 **Microsoft Edge**（需支持 WebHID API）
- **运行环境**：系统已安装 **Python 3**（macOS / Linux 通常自带；Windows 若未安装可从 Microsoft Store 或 python.org 安装）
- **连接方式**：请使用 **USB-C 数据线** 将键盘直连电脑（蓝牙模式不支持刷写）

---

## 二、启动步骤

### macOS / Linux
在解压后的目录中打开终端，运行：
```bash
chmod +x serve.sh
./serve.sh
```
浏览器会自动打开 `http://localhost:8765`（如未自动打开，请手动在 Chrome/Edge 中访问该地址）。

### Windows
直接**双击运行 `serve.bat`**，浏览器会自动打开 `http://localhost:8765`。

> **提示**：由于浏览器安全策略禁止在 `file://` 本地文件协议下调用 WebHID，请勿直接双击 `index.html`，务必通过上述脚本启动本地 `http://localhost:8765` 访问。

---

## 三、改键与刷写操作

1. 点击网页右上角 **「连接 USB-C 键盘」**，在浏览器弹出的设备列表中选择键盘并授权。
2. 连接成功后页面会自动读取当前固件版本（例如 `KA024_A_1.0.6` 或 `KA024_A_1.0.8`）。
3. 在顶部键盘图示中点击要修改的按键（例如 **「设备互联」**），从右侧选择目标功能（例如针对荣耀 MagicPad 4 / Android 平板可选择 **`0x029F` 最近任务**）或输入自定义 16 进制 Consumer Usage（`0x0000`–`0x0397`）。
4. 点击 **「直接 USB-C 刷入键盘」** 并确认，等待进度条到达 100%（约 15 秒，期间请勿拔掉数据线）。
5. 刷写完成后键盘会自动重启并生效；如需恢复原厂按键，随时点击页面上的 **「恢复全部原厂默认」** 再重新刷入即可。

---

## 四、安全说明

- 压缩包内已自带并自动校验官方原厂基线固件 `KA024_official_firmware.bin`（`KA024_A_1.0.8`）。
- 键盘主控采用 **Telink Dual-Bank A/B 双分区**机制：刷写过程仅写入备用分区，全部 4,033 块数据及尾部 CRC-32 校验通过后才切换分区重启，刷写中断不会导致变砖。
