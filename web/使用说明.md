# Lenovo KB331U（小新无线键盘 Air）WebHID 离线改键工具使用说明

本工具用于免拆机通过 USB-C 修改联想小新无线键盘 Air（KB331U，`17EF:619E`）整把键盘的固件键位（修改后**蓝牙与有线双模永久生效**，断电、重新配对不丢失）。

---

## 一、环境要求

- **浏览器**：桌面版 **Google Chrome** 或 **Microsoft Edge**（需支持 WebHID API）
- **运行环境**：系统已安装 **Python 3**（macOS / Linux 通常自带；Windows 若未安装可从 Microsoft Store 或 python.org 安装）
- **连接方式**：支持 **USB-C 数据线直连**（约 15 秒，推荐首选）或 **蓝牙无线连接**（Web Bluetooth，约 30–90 秒，支持电脑及安卓平板 Chrome 免线改键）

---

## 二、启动步骤

### macOS / Linux
在解压后的目录中打开终端，运行：
```bash
chmod +x serve.sh
./serve.sh
```
浏览器会自动打开 `http://localhost:8765`（如未自动打开，请手动在 Chrome/Edge 中访问该地址）。

### Windows
直接**双击运行 `serve.bat`**，浏览器会自动打开 `http://localhost:8765`。

> **提示**：由于浏览器安全策略禁止在 `file://` 本地文件协议下调用 WebHID，请勿直接双击 `index.html`，务必通过上述脚本启动本地 `http://localhost:8765` 访问。

---

## 三、改键与刷写操作

1. 点击网页右上角 **「连接 USB-C」**（插线直连，约 15 秒）或 **「蓝牙无线连接」**（免数据线，约 30–90 秒；若蓝牙弹窗找不到键盘，把键盘切到一个空闲通道长按 3 秒进入快闪配对状态再点连接）。
2. 连接成功后页面会自动读取键盘当前固件标签（原厂为 `KA024_A_1.0.8`，蓝牙模式下还会显示实时电量）。
3. **选择「BT1 / BT2 / BT3 分设备独立配置」或「三通道共用一套」**：
   - **三设备独立模式（推荐多设备）**：顶部直接分出 **`BT1`、`BT2`、`BT3`** 三个页面（可自定义备注名如 `MacBook` / `MagicPad` / `备用设备`），键盘切到哪个蓝牙通道就自动切换那台设备的整套键位、Fn 层与双击手势；可点右上角 **「✨ Mac 截图 + 平板搜索（推荐）」** 一键套用经典双设备方案（`BT1 Mac` 锁屏键变 `⌘+Shift+4` 框选截图、保留原生双击 `⌘` Spotlight；`BT2 MagicPad` 互联→多任务、右 Ctrl→回桌面、锁屏保留原厂、双击 `Alt/cmd`→`Meta+S` 60ms 错峰搜索）。
   - **三通道统一模式**：三台设备共用同一套键位；若不开启 Fn 层、双击和自定义多键组合，仍为 100% 纯数据改动（`64,516B`，0 字节代码改动）。
4. **修改当前通道的按键**：在键盘图上点击任意按键（BT1–BT3 蓝牙通道键锁定不可改），在下方 4 个标签页里自由选择：
   - **快捷功能（平板 / 媒体 / 音量）**：多任务视图、回到桌面、返回、语音助手、音量、媒体播放、屏幕亮度等。**内置 14 槽自动扩容**（≤7 种沿用原厂表，8–14 种自动切换 14 槽扩展表），静音/音量无需再妥协，多颗键也可共用同一功能；
   - **一键组合快捷键（支持 2–3 键，全键盘最多 16 组）**：每颗键独立绑定，互不占用原厂锁屏键！内置 **`📸 Mac 框选截图 ⌘+Shift+4`**、**`⌘+Shift+5`**、**`⌘+Shift+3`**、**`Meta+S（60ms 防误唤语音）`**、`Alt+Tab`、`⌘+C/V/W` 等；补丁自动补偿 Mac 蓝牙模式的修饰键互换，蓝牙与 USB-C 均能精准发出 `⌘` 组合键；
   - **普通按键**：支持搜索字母、数字、修饰键、F1–F24、导航键等；
   - **禁用此键**：仅在当前通道生效，不影响其他通道。
5. **开启当前通道的「⚡ 双击快捷键」（可选）**：
   - 在键盘图正下方的 **「⚡ 双击快捷键」** 卡片里勾选 **「开启双击触发」**（只影响当前所选通道，比如只在 `BT2 · MagicPad` 开启双击 `Alt/cmd → Meta+S`，`BT1 · Mac` 保持关闭，彻底零冲突）；
   - **内置 4 步错峰发送（防安卓/MagicOS 误唤语音助手）**：发组合键时自动按「先按住 `Meta` → 间隔 60ms → 按下 `S` → 间隔 60ms → 先松 `S` → 间隔 60ms → 最后松 `Meta`」分 4 个独立蓝牙报文发出（可调 40–120ms），彻底避免同时发包误触发语音助手。
6. **开启当前通道的「长按变 Fn 层」（可选）**：
   - 勾选键盘上方的 **「本通道开启长按变 Fn 层」**，可把 `CapsLock`（或右 Alt/右 Ctrl/Tab 等）变成 **长按进 Fn 层、轻点触发 Esc** 的双功能键，三个通道各自独立。
7. **设备名称与方案标签（可选）**：
   - 可自定义 13 位以内的 **方案识别标签**、**蓝牙显示名称**（≤18 位）与 **USB 有线名称**（≤30 位）。
8. 核对右侧「确认改动并写入键盘」分通道清单，点击 **「USB-C 写入键盘」** 或 **「蓝牙无线写入键盘」** 并确认等待完成。随时可点 **「全部恢复原厂」** 还原出厂设置。
9. 可用 **「备份方案 (.json)」/「导入方案 (.json)」** 跨电脑迁移配置（向下兼容旧版 v1–v4 方案），也支持用 **「从固件 .bin 读回」** 直接解析之前导出的任意固件。

## 四、安全说明

- 压缩包内已自带并自动校验官方原厂基线固件 `KA024_official_firmware.bin`（`KA024_A_1.0.8`）。
- 统一模式下未开启「长按变 Fn 层」「双击快捷键」与「自定义多键组合」时，仅修改数据表与长度常量（`64,516B`，**0 字节程序代码改动**）；开启三通道独立或扩展手势后，追加经 TC32 逐条核验与 CPU 全场景仿真的 840B v3 扩展补丁（`66,820B = 65.25 KB`，远低于 124 KB 分区上限），写入前会对全部 840B 机器码、6 处钩子、16 组组合表、3 通道键表、尾部联想校验魔数（`0x104E0`）及 CRC-32 做逐字节白名单核验，任意 1 bit 异常都会拦截拒绝刷写。
- 键盘主控采用 **Telink Dual-Bank A/B 双分区**机制：刷写过程仅写入备用分区，全部分块与尾部 CRC-32 及联想魔数校验通过后才切换分区重启，刷写中断不会导致变砖。
