# Lenovo KB331U（小新无线键盘 Air）WebHID 离线改键工具使用说明

本工具用于免拆机通过 USB-C 修改联想小新无线键盘 Air（KB331U，`17EF:619E`）整把键盘的固件键位（修改后**蓝牙与有线双模永久生效**，断电、重新配对不丢失）。

---

## 一、环境要求

- **浏览器**：桌面版 **Google Chrome** 或 **Microsoft Edge**（需支持 WebHID API）
- **运行环境**：系统已安装 **Python 3**（macOS / Linux 通常自带；Windows 若未安装可从 Microsoft Store 或 python.org 安装）
- **连接方式**：支持 **USB-C 数据线直连**（约 15 秒，推荐首选）或 **蓝牙无线连接**（Web Bluetooth，约 30–90 秒，支持电脑及安卓平板 Chrome 免线改键）

---

## 二、启动步骤

### macOS / Linux
在解压后的目录中打开终端，运行：
```bash
chmod +x serve.sh
./serve.sh
```
浏览器会自动打开 `http://localhost:8765`（如未自动打开，请手动在 Chrome/Edge 中访问该地址）。

### Windows
直接**双击运行 `serve.bat`**，浏览器会自动打开 `http://localhost:8765`。

> **提示**：由于浏览器安全策略禁止在 `file://` 本地文件协议下调用 WebHID，请勿直接双击 `index.html`，务必通过上述脚本启动本地 `http://localhost:8765` 访问。

---

## 三、改键与刷写操作

1. 点击网页右上角 **「连接 USB-C」**（插线直连，约 15 秒）或 **「蓝牙无线连接」**（免数据线，约 30–90 秒；若蓝牙弹窗找不到键盘，把键盘切到一个空闲通道长按 3 秒进入快闪配对状态再点连接）。
2. 连接成功后页面会自动读取键盘当前固件标签（原厂为 `KA024_A_1.0.8`，蓝牙模式下还会显示实时电量）。
3. **修改普通层按键**：在键盘图上点击任意按键（BT1–BT3 蓝牙通道键锁定不可改），在下方 4 个标签页里自由选择：
   - **快捷功能（平板 / 媒体 / 音量）**：多任务视图、回到桌面、返回、语音助手、音量、媒体播放、屏幕亮度等。**内置 14 槽自动扩容**（≤7 种沿用原厂表，8–14 种自动切换 14 槽扩展表），静音/音量无需再妥协，多颗键也可共用同一功能；
   - **一键组合快捷键（硬件双键宏）**：支持把任意两个按键（如 `Alt + Tab`、`⌘/Win + Space`、`Ctrl + C`、`⌘ + W`、`Win + L` 等）合成单键一键触发，有线与蓝牙双模生效；
   - **普通按键**：支持搜索字母、数字、修饰键、F1–F24、导航键等；
   - **禁用此键**：防止误触。
4. **开启「长按变 Fn 层」（可选）**：
   - 勾选键盘上方的 **「开启长按变 Fn 层」**，可把 `CapsLock`（或右 Alt/右 Ctrl/Tab 等）变成 **长按进 Fn 层、轻点触发 Esc** 的双功能键；
   - 切换到 **「Fn 组合层」** 标签，一键套用「高效方向/F键/媒体」（`Fn+IJKL → 方向键`、`Fn+1..= → F1–F12`、`Fn+空格 → 播放/暂停` 等），或逐键自由编辑；支持任意顺序松手防卡键。
5. **开启「双击快捷键」（可选，模仿 macOS 双击 Cmd 唤出搜索）**：
   - 勾选 **「双击快捷键」**，选择触发键（默认空格左侧 `左 Alt/cmd`），设置双击窗口（推荐 `0.32 秒`）和动作（默认 **`Meta/option + S`**，在 Android 平板/Windows 唤出搜索；也支持自定义任意两键组合或 Consumer 快捷功能）；
   - 平时按住该键配合其他键做组合键依然 **0 延迟无冲突**；仅在连续轻点两下时触发，且自动过滤多余的原键释放事件。
6. **设备名称与方案标签（可选）**：
   - 可自定义 13 位以内的 **方案识别标签**（以后连线一读即知当前刷的是哪套方案）；
   - 可永久自定义 **蓝牙显示名称**（≤18 位英文/数字/空格）与 **USB 有线名称**（≤30 位英文/数字/空格）。
7. 核对右侧「确认改动并写入键盘」清单，点击 **「USB-C 写入键盘」** 或 **「蓝牙无线写入键盘」** 并确认等待完成。写入后键盘会自动重启生效；随时可点 **「全部恢复原厂」** 还原出厂设置。
8. 可用 **「备份方案 (.json)」/「导入方案 (.json)」** 跨电脑迁移配置，也支持用 **「从固件 .bin 读回」** 直接解析之前导出的任意 7 槽、14 槽或含 Fn/双击功能的固件。

---

## 四、安全说明

- 压缩包内已自带并自动校验官方原厂基线固件 `KA024_official_firmware.bin`（`KA024_A_1.0.8`）。
- 未开启「长按变 Fn 层」与「双击快捷键」时，仅修改数据表与长度常量（64,516B，**0 字节程序代码改动**）；开启后追加经 TC32 逐条核验与 CPU 仿真的 476B 扩展补丁（65,284B），写入前仍会对全部机器码、6 处钩子、尾部联想校验魔数及 CRC-32 做逐字节白名单核验，任意 1 bit 异常都会拦截拒绝刷写。
- 键盘主控采用 **Telink Dual-Bank A/B 双分区**机制：刷写过程仅写入备用分区，全部分块与尾部 CRC-32 及联想魔数校验通过后才切换分区重启，刷写中断不会导致变砖。
